# results/

This folder holds the tables the repository's counts are computed from. All of it comes from the
author's working folder (final submission, July 2026). Nothing here was regenerated by running the
experiments; `python results/verify_summary.py` recomputes the arithmetic from these files.

## Files of record

| File | What it is |
|---|---|
| `replication_audit_final_20260425.csv` | Tuned track, paper vs replication side by side for all 150 (dataset, algorithm) pairs, per-metric errors, `Average_Error(%)`, `Status`. 143 evaluated rows, all PASS. 42 of the rows carry uniform-protocol values (see below). |
| `paper_values_final_20260425.csv` | The paper Table 2 targets used in that audit. |
| `replication_values_final_20260425.csv` | The replicated values used in that audit, with provenance. |
| `final_audit_summary_20260425.txt` | The author's summary of how the audit was built and its counts. |
| `exact_replication/baseline_phase1_comparison.csv` | Uniform-protocol track (Track 1): paper vs replication, errors and status per row. 42 PASS, 101 FAIL, 7 N/A. |
| `exact_replication/baseline_phase1_results_only.csv` | The replicated values of that run only. |
| `exact_replication/_42_pass_cells_spec.csv` | The 42 passing rows of the uniform-protocol run with their values and average errors. |
| `hue_canonical/` | The author's re-run of the canonical ITQ-HUE on the nine datasets whose tuned HUE is a bagged RandomForest approximation: runner script and one result CSV per dataset. |
| `earlier_workspace_tests/` | Result files and scripts of two side experiments (Test 1 and Test 2 of REPORT.md Section 5.4) from an earlier workspace of the author, runs of 2026-04-29, with a recomputation script and a README that says what each percentage means. Labelled as coming from the earlier workspace; not a file of record for Table 2 constants. |

The code that produced the uniform-protocol table is in `../exact_replication/`. The raw per-fold
outputs of that run are not included.

## How the author's folder was ranked

The working folder contains many nested snapshots and archives. The files above were taken from
`1 - FINAL SUBMISSION` (modified 2026-07-13, whose README names the audit CSVs as "results of
record") and checked against the top-level `results/` folder of the working tree (identical bytes)
and the author's correction notice of 2026-06-01. Folders carrying `DO_NOT_USE` markers (the older
nested `graduation project*` folders and the stale PDF) and `archive_*` folders were not used for
numbers. The files in this folder are unmodified copies, except for the removal of a local path in
`final_audit_summary_20260425.txt`, a changed default root in `hue_canonical/hue_runner.py`, and a
one-word comment edit in `../exact_replication/exact_replication_local.py`.

## The 42-row swap

On 2026-06-18 the author set the replicated values of the 42 tuned rows that also pass the uniform
protocol back to the uniform-protocol values. `verify_summary.py` checks that the 42 rows of
`_42_pass_cells_spec.csv` appear unchanged in `replication_audit_final_20260425.csv`. The `Replication_Source` column
of the audit file still names an older results file for some of these rows.

## One paper constant that differs from the printed table

CARVGOOD / ADASYN / AUC is 0.99 in `paper_values_final_20260425.csv`, the audit file, the baseline
file and the engine. In the printed Table 2 it is 0.98 (read from the table image of a converted
copy of the paper). The files were kept as the author has them; `verify_summary.py` uses 0.98 as a
documented override. The row passes under both values.
